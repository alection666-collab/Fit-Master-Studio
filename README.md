# FIT MASTER

Адаптивное веб-приложение-каталог тренажёров и упражнений с генератором персональных тренировочных программ.

## Возможности
- Каталог упражнений с фотографиями, мышечными группами и пошаговой техникой.
- Фильтры по группам мышц, поиск и карточки подробного описания.
- Ссылки на поиск видео с демонстрацией техники на YouTube.
- Генератор тренировочного сплита по возрасту, полу, росту, весу, уровню, цели и инвентарю.
- Ориентиры по подходам, повторениям, рабочему весу и отдыху.
- Сохранение программы в localStorage.
- Адаптивная навигация для смартфонов и ПК.

## Запуск
Откройте `index.html` в браузере или запустите локальный сервер:
```bash
python -m http.server 8000
```
Затем откройте `http://localhost:8000`.

Tailwind CSS подключается через CDN. Фотографии загружаются с images.unsplash.com. Для работы с фотографиями и стилями требуется интернет.

## Публикация на GitHub через GitHub CLI


## Важное замечание о нагрузке
Подбор рабочего веса в приложении — только приблизительная стартовая оценка по массе тела и уровню. Реальный вес зависит от техники, опыта, амплитуды, тренажёра и индивидуальных возможностей. Начинайте с лёгкой разминки, оставляйте запас повторений и не выполняйте движения через боль. Приложение не заменяет медицинскую консультацию и индивидуальную работу тренера.
