FIT MASTER — набор изображений, нарезанный из общего коллажа 5×6.
Файлы названы по ID упражнений в текущем каталоге приложения.
Важно: изображения являются демонстрационными кадрами из коллажа, не отдельными специально проверенными фотосессиями; перед включением в тренировочные инструкции нужна визуальная проверка соответствия позы и тренажёра.
